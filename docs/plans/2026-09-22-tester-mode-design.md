# 测试者模式设计

日期：2026-09-22

## 目标

正常玩很难打到后面的关卡，也就看不到后面的敌人。测试者模式让测试的人可以随意跳关、调敌人速度、快速过关、召唤任意敌人，
同时对小朋友保持隐藏。

## 入口与解锁

- 页面右下角有一个很淡的小锁按钮。点它弹出密码框，密码 `32167`，回车或点「确认」。
- 密码错误：提示「密码不对」，清空输入框，焦点留在输入框里。Esc、点「取消」或点遮罩都会关闭弹窗。
- 密码正确：小锁消失，左上角出现「测试者模式」按钮，点它展开或收起面板。面板最高 60vh，在常见的横屏上会停在弓箭手头顶上方，
  放不下的内容在面板里滚动。
- 解锁状态存在 `sessionStorage`：刷新后仍然解锁，关掉标签页后恢复隐藏。
- 面板底部的「退出测试者模式」会马上重新隐藏，并把所有开关恢复默认。
- 密码写在前端代码里，只能挡住小朋友，不是真正的安全措施。

## 面板功能

| 分组 | 功能 | 行为 |
| --- | --- | --- |
| 关卡 | 第 N 关 + 跳转 | 输入 1–100，回车或点「跳转」。在开始、失败、通关画面会开一局新战役；在战斗中或商店里跳转，金币和装备都保留。跳到低档位时，还没解锁的箭会换回普通箭。 |
| 关卡 | Tier 1–10 | 跳到该档第一关（(Tier − 1) × 10 + 1）。鼠标悬停显示这一档的敌人。 |
| 敌人速度 | 暂停 / 0.5× / 1× / 2× | 敌人的移动、攻击、状态效果和出怪计时都乘这个倍率。死亡动画、箭和粒子不受影响，所以暂停时照样能打字射箭。瞄准提前量也按倍率算。 |
| 开关 | 杀一个敌人就过关 | 打开后，下一次击杀会让场上其他敌人一起倒下，本关停止出怪，然后照常进入商店。 |
| 开关 | 城墙无敌 | 敌人照常攻击城墙，但城墙不掉血。 |
| 按钮 | 立即过关 | 场上敌人全部倒下，本关停止出怪，然后照常进入商店（第 100 关进入通关画面）。只在战斗中生效。 |
| 按钮 | +1000 金币 / +10 训练点 / +10 特殊箭 | 任何画面都能用，方便测试商店升级和特殊箭。 |
| 召唤 | 10 种敌人 | 直接出现在画面右侧（x ≈ 660–990，随机分散开），暂停时也看得到。不占本关的敌人数量，Boss 按当前档位加强。只在战斗中生效。 |

## 实现

- `src/testerMode.mjs`
  - 纯函数（有单元测试）：`checkTesterPassword`、`clampLevel`、`tierStartLevel`、`createTesterSettings`、
    `grantTesterResources`、`describeTierEnemies`。
  - `mountTesterMode(api)`：创建小锁、密码框、「测试者模式」按钮和面板，样式也在模块内。
- `src/gameApp.mjs` 只加几个小钩子：
  - `app.tester` 设置：`oneKillClears`、`invincible`、`enemySpeed`。
  - 新增 `jumpToLevel`、`finishLevelNow`、`summonEnemy`；`startCampaign(startLevel)`。
  - 从 `spawnEnemy` 提取出 `createLevelEnemy`，随机数调用顺序不变，同一个种子的战役仍然完全复现。
  - 测试者界面里的按键在界面根节点停止冒泡，不会传到游戏，所以在密码框或关卡框里按回车、数字键不会开局、换箭或在商店里买东西。
    面板按钮点完、跳关成功后都会让出焦点，打字马上回到游戏。
  - `render_game_to_text` 输出 `tester` 状态，方便自动测试。

## 测试

- `npm test`：`test/testerMode.test.mjs` 覆盖纯函数。
- `work/tester-mode-playtest.mjs`：用 Playwright 在真实浏览器里跑一遍解锁、键盘隔离、刷新保持解锁、跳关、Tier、
  暂停和 2× 速度、召唤全部 10 种敌人、城墙无敌、立即过关、加资源、一杀过关、第 100 关通关和退出。
